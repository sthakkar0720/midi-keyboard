# midi-keyboard
<h1>A custom MIDI keypad with slides, switches, rotary encoders, and capacitive touch. Built with the Hack Club Half Life guide.</h1>
I chose to make this because it is a music device and that is cool and it is one more cool piece of tech to put on my desk by my laptop. It provides accessibility for mixing my own music and I am hoping it works with spotify!
